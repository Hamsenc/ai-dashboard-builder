Hướng dẫn nội bộ team Data

Tài liệu cho team Data vận hành app — chưa mở cho user ngoài. Chỉ người có quyền embed/admin mới thấy trang này.

App gồm những gì

🗂️
Tư vấn chọn bảng
Mô tả nhu cầu bằng lời thường → app gợi ý bảng Serving kèm lý do. Bấm 1 bảng để xem mô tả cột, grain, cảnh báo PII và xem trước dữ liệu thật. Tích chọn bảng → khay "Bảng đang chọn" để copy prompt / tải data preview (50 dòng/bảng) cho AI. Xem ở tab 🗂️ Tư vấn chọn bảng.
📊
Nhúng dashboard vào Lark
Upload 1 file HTML → nhận link public /d/{id} để dán vào Lark. Dashboard có thể lấy dữ liệu sống từ BigQuery, file Excel/CSV hoặc Lark Base. Sửa/thay file HTML sau này link vẫn giữ nguyên. Xem ở tab 📊 Nhúng dashboard vào Lark.
🛠️
Quản trị (role admin)
Cấp/thu hồi role, duyệt yêu cầu cấp quyền, xem link đang hoạt động, lịch sử nhúng và bảng được xem nhiều nhất 30 ngày gần nhất. Xem ở tab 🛠️ Quản trị.

🔑 Phân quyền

  • embed: tạo/sửa/thu hồi dashboard nhúng, và xem được trang Hướng dẫn này.
  • admin: có quyền embed + xem toàn bộ log + phân quyền cho người khác. Chỉ super admin (khai báo ở env SUPER_ADMIN_EMAILS) mới cấp/thu hồi được role admin.
  • Người chưa có quyền vào tab Nhúng sẽ thấy nút "Yêu cầu cấp quyền" → yêu cầu hiện ở mục "Yêu cầu đang chờ duyệt" trong tab Quản trị để admin duyệt.

🔌 Nguồn dữ liệu sống

Chọn ở mục "Dữ liệu sống" khi upload. File HTML tự gọi fetch(...) lúc trang load — app tự chèn <base> nên URL tương đối luôn đúng. Kết quả cache 15 phút: số liệu mới nhất có thể trễ tối đa 15 phút.

  • 🗄️ Bảng BigQuery — fetch('data') trả {columns, rows}. Không nhận SQL tự do, chỉ nhận spec JSON (table_id, columns, aggregations[], filters[], order_by[], joins[], limit mặc định 500). Hàm: SUM, COUNT, COUNT_DISTINCT, AVG, MIN, MAX. Nhiều bảng: bọc vào {"specs": {"tên": {...}}}, tối đa 10 bảng, tổng limit ≤ 100.000 dòng — khi đó fetch('data') trả {tên: {columns, rows}}. Bộ lọc cho người xem tự đổi: filter có param, HTML gọi fetch('data?tu_ngay=2026-10-01').
  • 📄 File Excel/CSV — cho dữ liệu không có trong BigQuery. fetch('data-file') trả nguyên file gốc, tự đọc bằng SheetJS. Cập nhật số = upload file mới, không đổi link/HTML.
  • 📋 Lark Base — dùng được cùng lúc với 2 nguồn trên. Mỗi dòng tên | link, tối đa 5 bảng, 20.000 dòng/bảng. File Base phải share cho bot "Bùi Trường Linh". fetch('lark-data') trả {tên: {columns, rows}}; link có view= thì chỉ lấy theo bộ lọc của view đó.

🛠️ Các cách build dashboard

Prompt mẫu

Prompt dùng nhờ AI (Claude Code / trợ lý nội bộ) làm dashboard — bấm sao chép rồi dán thẳng cho AI.

Skill nên cài

"Skill" là bộ hướng dẫn đóng gói sẵn để Claude Code làm đúng quy trình của app (đọc bảng, thiết kế dashboard, nhúng Lark...). Tải file bên dưới, đặt vào .claude/skills/<tên-skill>/SKILL.md trong project là dùng được ngay.

🤝 Cách 1 — AI không có quyền BigQuery

Dùng khi tài khoản Claude/ChatGPT đang dùng KHÔNG kết nối được BigQuery công ty. App chuẩn bị sẵn dữ liệu mẫu + hướng dẫn để AI tự viết file HTML.

  1. Tích chọn bảng. Ở tab 🗂️ Tư vấn chọn bảng, tích các bảng cần dùng (tối đa 10 bảng nếu cần dữ liệu sống).
  2. Lấy prompt + file mẫu. Trong khay "Bảng đang chọn": bấm "📋 Copy prompt" rồi "📄 Tải data preview kèm mô tả" (schema, số dòng thật, grain, 50 dòng mẫu/bảng).
  3. Nhờ AI thiết kế. Dán prompt + đính kèm file .txt. AI trả về 2 file: dashboard.html và data_query_spec.json.
  4. Upload. Tab 📊 Nhúng dashboard vào Lark → nhập tên → chọn dashboard.html ở ô "File HTML" → Dữ liệu sống "🗄️ Bảng BigQuery" → "📝 Nhập JSON trực tiếp" → dán nội dung data_query_spec.json.
  5. Bấm Upload → copy link /d/{id} → dán vào Lark.

50 dòng chỉ để AI xem cấu trúc — dashboard khi mở luôn lấy số liệu thật.

🛠️ Cách 2 — Claude Code có quyền BigQuery

AI tự đọc được dữ liệu thật, không cần tải file mẫu. Cài skill lark-dashboard-embed ở trên rồi:

  1. Chọn bảng. Tự chọn ở tab Tư vấn chọn bảng, hoặc để AI tự tìm.
  2. Nhờ AI thiết kế + viết file HTML. AI đọc schema + dữ liệu thật, soạn dashboard và cấu hình dữ liệu sống.
  3. Tự upload ở 📊 Nhúng dashboard vào Lark. AI không upload hộ được (cần đăng nhập Lark của chính bạn) — dán đúng file + JSON AI đưa.

✏️ Sửa, chia sẻ, thu hồi

  • Sửa: mục "Dashboard của tôi" → "✏️ Sửa". Để trống ô File HTML nếu giữ giao diện cũ; chọn file mới để thay — link giữ nguyên, không cần gửi lại.
  • Cập nhật số liệu từ file: sửa dashboard, tải file Excel/CSV mới lên.
  • Chia sẻ quyền quản lý: mở chi tiết dashboard → mục "Chia sẻ", nhập email (hoặc * = tất cả user nội bộ), chọn "Chỉ xem" / "Có thể sửa".
  • Thu hồi: bấm "Thu hồi" — link /d/{id} ngừng hoạt động ngay.
