🛠️ Các cách build dashboard

Prompt mẫu

Vài prompt dùng nhờ AI (Claude Code / trợ lý nội bộ) làm dashboard hoặc khai thác dữ liệu — bấm sao chép rồi dán thẳng cho AI. Danh sách sẽ được cập nhật thêm theo thời gian.

Skill nên cài

"Skill" là 1 bộ hướng dẫn đóng gói sẵn để Claude Code biết cách làm đúng quy trình của app này (đọc bảng, thiết kế dashboard, nhúng Lark...) thay vì phải giải thích lại từ đầu mỗi lần. Tải file bên dưới, đặt vào .claude/skills/<tên-skill>/SKILL.md trong project của bạn là dùng được ngay.

🤝 Cách 1 — Tự làm bằng AI riêng của bạn (không cần quyền BigQuery)

Dùng khi cần thiết kế phức tạp hơn mẫu có sẵn, và tài khoản Claude/ChatGPT của bạn KHÔNG kết nối được BigQuery của công ty. App chuẩn bị sẵn dữ liệu mẫu + hướng dẫn để AI riêng của bạn tự viết file HTML.

  1. Tích chọn bảng cần dùng. Ở tab 🗂️ Tư vấn chọn bảng, mô tả nhu cầu rồi tích checkbox ở các bảng phù hợp (tối đa 3 bảng nếu muốn dashboard có dữ liệu tự cập nhật) — bảng đã chọn hiện ở khay "Bảng đang chọn" cuối trang.
  2. Tải file cho AI. Trong khay đó, bấm "📋 Copy prompt" rồi "📄 Tải data preview kèm mô tả" — file tải về gồm schema, số dòng thật, grain, và 50 dòng mẫu của (các) bảng đã chọn, kèm sẵn hướng dẫn viết đúng chuẩn.
  3. Nhờ AI riêng của bạn thiết kế. Mở ChatGPT/Claude cá nhân → dán prompt đã copy → đính kèm file .txt vừa tải. AI sẽ trả về đúng 2 file: dashboard.html và data_query_spec.json.
  4. Upload lên app. Vào tab 📊 Nhúng dashboard vào Lark → "📁 Upload file HTML có sẵn" → chọn dashboard.html → bật "Dữ liệu sống" → "🗄️ Bảng BigQuery" → "📝 Nhập JSON trực tiếp" → dán nguyên nội dung data_query_spec.json.
  5. Bấm Upload → copy link /d/{id} → dán vào Lark.

50 dòng chỉ để AI xem cấu trúc — dashboard khi mở luôn tự lấy số liệu thật, không hiển thị đúng 50 dòng đó.

🛠️ Cách 2 — Nhờ Claude Code làm hộ toàn bộ (cần Claude đã có quyền BigQuery)

Chỉ dùng được nếu Claude Code của bạn (hoặc của admin) đã kết nối thẳng tới BigQuery của công ty — khác Cách 1 ở chỗ AI tự đọc được dữ liệu thật, không cần bạn tải file mẫu. Sau khi cài skill lark-dashboard-embed ở trên, quy trình gồm:

  1. Chọn bảng. Tự chọn ở tab Tư vấn chọn bảng, hoặc để AI tự tìm nếu bạn chỉ mô tả chung chung.
  2. Nhờ AI thiết kế + viết file HTML. AI đọc schema và dữ liệu thật, tự soạn dashboard (KPI, biểu đồ) và cấu hình "dữ liệu sống" nếu muốn số tự cập nhật mỗi lần mở link.
  3. Bạn upload file lên 📊 Nhúng dashboard vào Lark. AI không upload hộ được (cần đăng nhập Lark của chính bạn) — chỉ cần dán đúng file + JSON cấu hình AI đưa.

Không có quyền upload? Vào tab Nhúng dashboard rồi bấm "Yêu cầu cấp quyền".

🧩 Cách 3 — Dùng dashboard mẫu có sẵn (không cần code, nhanh nhất)

Phù hợp khi nhu cầu đơn giản: vài KPI + 1 biểu đồ theo ngày hoặc theo nhóm. App tự lắp dashboard, không cần tự viết HTML hay biết SQL.

  1. Tìm bảng dữ liệu. Ở tab 🗂️ Tư vấn chọn bảng, mô tả báo cáo muốn làm — bảng phù hợp sẽ được bold và đẩy lên đầu danh sách (không ẩn các bảng khác, vẫn xem được nếu advisor đoán chưa đúng).
  2. Chọn "Dashboard mẫu". Vào tab 📊 Nhúng dashboard vào Lark → chọn "🧩 Dashboard mẫu (không cần code)".
  3. Chọn 1 kiểu dashboard. Xu hướng theo thời gian (biểu đồ đường theo ngày), So sánh theo nhóm (biểu đồ cột theo brand/kênh...), hoặc Bảng dữ liệu chi tiết (chỉ KPI + bảng).
  4. Chọn bảng + chỉ số. Chọn bảng nguồn, cột muốn chia nhóm (nếu kiểu dashboard cần), rồi thêm từng chỉ số (cột số + cách tính Tổng/Đếm/Trung bình).
  5. Bấm "Tạo dashboard" → copy link /d/{id} hiện ra → dán vào Lark.
