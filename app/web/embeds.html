Nhúng dashboard vào Lark

Upload 1 file HTML dashboard có sẵn, hoặc chọn bảng dữ liệu + vài biểu đồ để app tự tạo dashboard — cả 2 cách đều ra 1 link chia sẻ công khai, nhúng iframe được vào Lark, ai có link đều xem được, không cần đăng nhập.

Upload dashboard mới

Đang sửa "" — link giữ nguyên, kể cả khi thay file HTML.
Để trống nếu giữ file cũ. Chọn file mới để thay giao diện — link giữ nguyên, không cần gửi lại.

Trong file HTML, gọi fetch('data') lúc trang load để lấy JSON {columns, rows} — app tự chèn <base> nên URL tương đối luôn trỏ đúng chỗ. Nếu dùng nhiều bảng (chế độ JSON, tối đa 3 bảng/dashboard) thì fetch('data') trả về {tên_bảng: {columns, rows}, ...} thay vì 1 object phẳng.

Bảng dữ liệu nguồn
Cột hiển thị / nhóm theo
Tính tổng hợp (tùy chọn — VD: Tổng doanh thu theo từng brand)
Lọc dữ liệu (tùy chọn)
Sắp xếp theo (tùy chọn)
Giới hạn số dòng trả về
Spec JSON

Không hỗ trợ SQL tự do — chỉ nhận spec JSON: table_id, columns, aggregations[] ({column, fn, alias}), filters[] ({column, op, value, type}), order_by[] ({column, direction}), limit (tối đa 20000, mặc định 500).

Cần dữ liệu từ nhiều bảng trong cùng 1 dashboard? Bọc các spec trên vào 1 object {"specs": {"tên_1": {...}, "tên_2": {...}}} — tối đa 3 bảng, mỗi spec con vẫn theo đúng cấu trúc ở trên (chỉ đặt tên khác nhau cho từng cái). Chỉ hỗ trợ ở chế độ JSON này, dropdown chỉ chọn được 1 bảng.

Dùng khi dữ liệu KHÔNG nằm trong BigQuery (VD: file Excel/CSV bạn tự theo dõi). Server chỉ lưu lại nguyên file, không đọc/parse gì cả — trong file HTML, gọi fetch('data-file') lúc trang load để lấy file gốc rồi tự đọc bằng SheetJS: fetch('data-file').then(r=>r.arrayBuffer()).then(buf=>XLSX.read(buf,{type:'array'})). Sau này cần cập nhật số liệu, chỉ cần tải file mới lên đây — không cần đổi link/HTML.

📋 Thêm bảng Lark Base (tùy chọn — dùng được cùng lúc với BigQuery/File ở trên)

Để trống nếu không dùng. Mở đúng bảng trong Lark Base, copy link trên thanh địa chỉ. Mỗi dòng 1 bảng, dạng tên | link (tên chỉ chữ/số/gạch dưới, tối đa 5 bảng). Mỗi file Base phải được share cho bot "Bùi Trường Linh", nếu không sẽ báo lỗi lúc lưu. Trong file HTML gọi fetch('lark-data') để lấy {tên: {columns, rows}}; nếu link có view= thì chỉ lấy dữ liệu theo bộ lọc của view đó.
